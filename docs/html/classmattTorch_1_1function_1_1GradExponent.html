Detailed Description

Gradient function for raising a tensor to an integer power.

The GradExponent class represents the exponentiation operation in the computational graph, computing gradients for raising a tensor to an integer power. For the operation \(C = A^n\) where \(A\) is a tensor and \(n\) is an integer exponent, the gradient computation follows from the power rule:

\[ \frac{\partial C}{\partial A} = n \cdot A^{n-1} \]

During backpropagation, the incoming gradient \(\frac{\partial L}{\partial C}\) is multiplied elementwise with the derivative according to the chain rule:

\[ \frac{\partial L}{\partial A} = \frac{\partial L}{\partial C} \odot \frac{\partial C}{\partial A} = \frac{\partial L}{\partial C} \odot (n \cdot A^{n-1}) \]

This GradFunction saves the input tensor and the integer exponent from the forward pass as both are required to compute the gradient during the backward pass using the power rule.

Computes and propagates gradients for the exponentiation operation.

Implements the backward pass for exponentiation using the power rule. The gradient is computed by raising the input tensor to the power (n-1), multiplying by the exponent n, and then multiplying elementwise with the incoming gradient. The method calls backward() on the parent tensor's GradFunction to continue the backpropagation process.

When higherDerivative is false, gradient tracking is disabled on the saved tensor to prevent construction of a new computational graph during backpropagation.

Parameters
inputGradientThe gradient of the loss with respect to the output of the exponentiation operation
higherDerivativeIf true, enables construction of a computational graph during the backward pass for higher-order derivatives; if false, disables gradient tracking on saved tensors
