Detailed Description

A sequential neural network composed of an ordered collection of layers.

The Network class represents a feedforward neural network in which an input tensor is passed sequentially through each layer in the order they were added. The Network holds raw pointers to its Layer objects as well as shared pointers to all learnable parameter tensors across the network. Network objects are intended to be constructed via the NetworkBuilder class, which provides a fluent interface for assembling layers and collecting their parameters.

The Network class also provides functionality for saving and loading the learned parameter values to and from CSV files, as well as generating a text summary of the network architecture.

See also
NetworkBuilder for the builder class used to construct Network objects.
Layer for the base class from which all network layers derive.
Optimiser for the classes that optimise the parameters of this network.

void mattTorch::Network::loadParameters ( const std::string & path)

Loads network parameter values from a CSV file.

Reads each line of the specified CSV file and populates the corresponding parameter tensor with the comma-separated double values. The file is expected to have the same format as produced by saveParameters, with each row corresponding to one parameter tensor in the same order.
