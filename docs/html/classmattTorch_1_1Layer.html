Detailed Description

Abstract base class for all neural network layers.

The Layer class defines the interface that all layers in a mattTorch neural network must implement. Each layer must provide a forward pass method that takes an input tensor and returns an output tensor, a method to report the number of learnable parameters it contains, and a method to return shared pointers to its learnable parameter tensors. The forward pass of each layer participates in the computational graph, allowing gradients to be propagated back through the layer during backpropagation.

See also
Network for the class that holds and sequences layers during forward propagation.
TensorView for the tensor class used to represent inputs, outputs and learnable parameters.
