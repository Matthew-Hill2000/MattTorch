Detailed Description

Gradient function for tensor-scalar division.

The GradDivideScalar class represents division operations involving a tensor and a scalar value in the computational graph, computing gradients for operations of the form \(C = A / s\) or \(C = s / A\) where \(A\) is a tensor and \(s\) is a scalar value. The numerator flag determines which form was used during the forward pass.

For the operation \(C = A / s\) (numerator = true), the gradient computation follows from:

\[ \frac{\partial C}{\partial A} = \frac{1}{s} \]

and during backpropagation:

\[ \frac{\partial L}{\partial A} = \frac{\partial L}{\partial C} \cdot \frac{1}{s} \]

For the operation \(C = s / A\) (numerator = false), the gradient computation follows from:

\[ \frac{\partial C}{\partial A} = -\frac{s}{A^2} \]

and during backpropagation:

\[ \frac{\partial L}{\partial A} = \frac{\partial L}{\partial C} \odot \left(-\frac{s}{A^2}\right) \]

This GradFunction saves the scalar value, a shared pointer to the tensor from the forward pass, and a flag indicating whether the tensor was the numerator or denominator, as all are required to compute the gradient during the backward pass.

Computes and propagates gradients for the tensor-scalar division operation.

Implements the backward pass for tensor-scalar division with behaviour determined by the numerator flag. When the tensor was the numerator, the incoming gradient is divided by the scalar value. When the tensor was the denominator, the gradient is computed using the quotient rule involving the saved tensor and scalar. The method calls backward() on the parent tensor's GradFunction to continue the backpropagation process.

Parameters
inputGradientThe gradient of the loss with respect to the output of the division operation
higherDerivativeIf true, enables construction of a computational graph during the backward pass for higher-order derivatives; if false, disables gradient tracking
