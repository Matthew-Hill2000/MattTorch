Detailed Description

A Rectified Linear Unit activation layer.

The ReLU class implements the ReLU activation function as a network layer, applying the elementwise transformation:

\[ f(x) = \max(0, x) \]

to the input tensor during the forward pass. The input tensor and its shape are stored internally for reference. This layer contains no learnable parameters.

See also
Layer for the base class from which this class derives.
TensorView::ReLU() for the underlying tensor operation that performs the elementwise ReLU computation and constructs the computational graph node.
