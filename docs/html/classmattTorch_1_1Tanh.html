Detailed Description

A hyperbolic tangent activation layer.

The Tanh class implements the tanh activation function as a network layer, applying the elementwise transformation:

\[ f(x) = \tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}} \]

to the input tensor during the forward pass by delegating to TensorView::tanh(). This layer contains no learnable parameters.

See also
Layer for the base class from which this class derives.
TensorView::tanh() for the underlying tensor operation that performs the elementwise tanh computation and constructs the computational graph node.
