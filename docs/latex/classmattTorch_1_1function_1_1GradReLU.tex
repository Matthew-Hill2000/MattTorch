\doxysubsection{Detailed Description}
Gradient function for the Rectified Linear Unit (\doxylink{classmattTorch_1_1ReLU}{Re\+LU}) activation function. 

The \doxylink{classmattTorch_1_1function_1_1GradReLU}{Grad\+Re\+LU} class represents the \doxylink{classmattTorch_1_1ReLU}{Re\+LU} activation function in the computational graph, computing gradients for the elementwise operation that outputs the maximum of zero and the input. For the operation  $C =
\text{ReLU}(A) = \max(0, A)$, the gradient computation follows from the piecewise derivative:\+      \[    \frac{\partial C}{\partial A} = \begin{cases}
      1 & \text{if } A > 0 \\
      0 & \text{if } A \leq 0
    \end{cases}
\]

During backpropagation, the incoming gradient  $\frac{\partial L}{\partial
C}$ is multiplied elementwise with a mask indicating which elements of the input were positive according to the chain rule:\+      \[    \frac{\partial L}{\partial A_i} = \begin{cases}
      \frac{\partial L}{\partial C_i} & \text{if } A_i > 0 \\
      0 & \text{if } A_i \leq 0
    \end{cases}
\]

This \doxylink{classmattTorch_1_1GradFunction}{Grad\+Function} saves a backward mask tensor computed during the forward pass, which contains 1 for positive elements and 0 for non-\/positive elements. The mask is used to efficiently apply the gradient gating during the backward pass without recomputing comparisons.

Computes and propagates gradients for the \doxylink{classmattTorch_1_1ReLU}{Re\+LU} activation. 

Implements the backward pass for the \doxylink{classmattTorch_1_1ReLU}{Re\+LU} activation by multiplying the incoming gradient elementwise with the saved backward mask. This effectively passes through the gradient for elements where the input was positive and zeros out the gradient for elements where the input was non-\/positive, reflecting the piecewise linear nature of \doxylink{classmattTorch_1_1ReLU}{Re\+LU}. The method calls \doxylink{classmattTorch_1_1function_1_1GradReLU_a1b5e6b312079324bf8d8169f24df6a5d}{backward()} on the parent tensor\textquotesingle{}s \doxylink{classmattTorch_1_1GradFunction}{Grad\+Function} to continue the backpropagation process.

When higher\+Derivative is false, gradient tracking is disabled on the backward mask to prevent construction of a new computational graph during backpropagation.
