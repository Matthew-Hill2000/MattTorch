\doxysubsection{Detailed Description}
Gradient function for elementwise tensor multiplication. 

The \doxylink{classmattTorch_1_1function_1_1GradMultiply}{Grad\+Multiply} class represents the elementwise multiplication operation in the computational graph, computing gradients for the Hadamard product of two tensors. For the operation $C = A \odot B$ where $\odot$ denotes elementwise multiplication, the gradient computation follows from the derivatives:\+    \[    \frac{\partial C}{\partial A} = B, \quad \frac{\partial C}{\partial B}
= A
\]

During backpropagation, the incoming gradient  $\frac{\partial L}{\partial
C}$ is multiplied elementwise with the appropriate saved tensor according to the chain rule:\+    \[    \frac{\partial L}{\partial A} = \frac{\partial L}{\partial C} \odot
\frac{\partial C}{\partial A} = \frac{\partial L}{\partial C} \odot B
\]    \[    \frac{\partial L}{\partial B} = \frac{\partial L}{\partial C} \odot
\frac{\partial C}{\partial B} = \frac{\partial L}{\partial C} \odot A
\]

This \doxylink{classmattTorch_1_1GradFunction}{Grad\+Function} saves copies of both input tensors as they are required to compute the gradients with respect to each input during the backward pass.

Computes and propagates gradients for the elementwise multiplication operation. 

Implements the backward pass for elementwise multiplication by multiplying the incoming gradient with the appropriate saved tensor for each parent. For the first parent, the gradient is multiplied elementwise with the second saved tensor; for the second parent, the gradient is multiplied elementwise with the first saved tensor. The method calls \doxylink{classmattTorch_1_1function_1_1GradMultiply_ae6a3f087eca3cbdb7a8bb1fa65aa25c4}{backward()} on each parent\textquotesingle{}s \doxylink{classmattTorch_1_1GradFunction}{Grad\+Function} to continue the backpropagation process.

When higher\+Derivative is false, gradient tracking is disabled on the saved tensors to prevent construction of a new computational graph during backpropagation.
