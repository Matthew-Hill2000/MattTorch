\doxysubsection{Detailed Description}
Abstract base class for all loss functions. 

The \doxylink{classmattTorch_1_1Criterion}{Criterion} class defines the interface for computing loss values during neural network training. Specific loss functions such as cross-\/entropy or mean squared error are intended to derive from this class and implement the calculate\+Loss method with the appropriate loss computation. The resulting loss tensor participates in the computational graph, allowing gradients to be propagated back through the loss function during backpropagation.
