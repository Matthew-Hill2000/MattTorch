\doxysubsection{Detailed Description}
A Rectified Linear Unit activation layer. 

The \doxylink{classmattTorch_1_1ReLU}{Re\+LU} class implements the \doxylink{classmattTorch_1_1ReLU}{Re\+LU} activation function as a network layer, applying the elementwise transformation:\+   \[    f(x) = \max(0, x)
\] to the input tensor during the forward pass. The input tensor and its shape are stored internally for reference. This layer contains no learnable parameters.
