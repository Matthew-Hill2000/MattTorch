\doxysubsection{Detailed Description}
A hyperbolic tangent activation layer. 

The \doxylink{classmattTorch_1_1Tanh}{Tanh} class implements the tanh activation function as a network layer, applying the elementwise transformation:\+   \[    f(x) = \tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}
\] to the input tensor during the forward pass by delegating to \doxylink{classmattTorch_1_1TensorView_a1e687142d7026837d7b4d04665874f75}{Tensor\+View::\+tanh()}. This layer contains no learnable parameters.
