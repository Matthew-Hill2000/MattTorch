\doxysubsection{Detailed Description}
Gradient function for elementwise tensor subtraction. 

The \doxylink{classmattTorch_1_1function_1_1GradSubtract}{Grad\+Subtract} class represents the subtraction operation in the computational graph, computing gradients for the elementwise difference of two tensors. For the operation $C = A - B$, the gradient computation follows from the derivatives:\+    \[    \frac{\partial C}{\partial A} = 1, \quad \frac{\partial C}{\partial B}
= -1
\]

During backpropagation, the incoming gradient  $\frac{\partial L}{\partial
C}$ is passed to both parent tensors according to the chain rule, with the gradient being negated for the second operand:\+    \[    \frac{\partial L}{\partial A} = \frac{\partial L}{\partial C} \cdot
\frac{\partial C}{\partial A} = \frac{\partial L}{\partial C}
\]    \[    \frac{\partial L}{\partial B} = \frac{\partial L}{\partial C} \cdot
\frac{\partial C}{\partial B} = -\frac{\partial L}{\partial C}
\]

This \doxylink{classmattTorch_1_1GradFunction}{Grad\+Function} saves copies of both input tensors, though they are not strictly required for the gradient computation of subtraction. The saved tensors may be used for higher-\/order derivative computations or for consistency with the gradient function interface.

Computes and propagates gradients for the subtraction operation. 

Implements the backward pass for elementwise subtraction by passing the incoming gradient unchanged to the first parent tensor and negating it for the second parent tensor. Since the derivative of subtraction with respect to the first input is +1 and with respect to the second input is -\/1, the gradient is propagated accordingly. The method calls \doxylink{classmattTorch_1_1function_1_1GradSubtract_a953a956db45065056e217527c5ac9ec2}{backward()} on each parent\textquotesingle{}s \doxylink{classmattTorch_1_1GradFunction}{Grad\+Function} to continue the backpropagation process.

When higher\+Derivative is false, gradient tracking is disabled on the saved tensors to prevent construction of a new computational graph during backpropagation.
