\doxysubsection{Detailed Description}
Gradient function for raising a tensor to an integer power. 

The \doxylink{classmattTorch_1_1function_1_1GradExponent}{Grad\+Exponent} class represents the exponentiation operation in the computational graph, computing gradients for raising a tensor to an integer power. For the operation $C = A^n$ where $A$ is a tensor and $n$ is an integer exponent, the gradient computation follows from the power rule:\+   \[    \frac{\partial C}{\partial A} = n \cdot A^{n-1}
\]

During backpropagation, the incoming gradient  $\frac{\partial L}{\partial
C}$ is multiplied elementwise with the derivative according to the chain rule:\+     \[    \frac{\partial L}{\partial A} = \frac{\partial L}{\partial C} \odot
\frac{\partial C}{\partial A} = \frac{\partial L}{\partial C} \odot (n
\cdot A^{n-1})
\]

This \doxylink{classmattTorch_1_1GradFunction}{Grad\+Function} saves the input tensor and the integer exponent from the forward pass as both are required to compute the gradient during the backward pass using the power rule.

Computes and propagates gradients for the exponentiation operation. 

Implements the backward pass for exponentiation using the power rule. The gradient is computed by raising the input tensor to the power (n-\/1), multiplying by the exponent n, and then multiplying elementwise with the incoming gradient. The method calls \doxylink{classmattTorch_1_1function_1_1GradExponent_aac3447f13f16527ca24cebf1fccb0e9b}{backward()} on the parent tensor\textquotesingle{}s \doxylink{classmattTorch_1_1GradFunction}{Grad\+Function} to continue the backpropagation process.

When higher\+Derivative is false, gradient tracking is disabled on the saved tensor to prevent construction of a new computational graph during backpropagation.
