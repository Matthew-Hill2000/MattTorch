\doxysubsection{Detailed Description}
Gradient function for broadcasting a tensor along a new dimension. 

The \doxylink{classmattTorch_1_1function_1_1GradBroadcast}{Grad\+Broadcast} class represents the broadcasting operation in the computational graph, computing gradients for expanding a tensor by adding a new dimension and replicating the tensor\textquotesingle{}s values along that dimension. For the operation where tensor $A$ of shape $(d_1, \ldots, d_n)$ is broadcast to tensor $C$ of shape  $(d_1, \ldots, d_{pos}, N, d_{pos+1},
\ldots, d_n)$ at position $pos$, the gradient computation follows from:\+    \[    \frac{\partial C_{i_1,\ldots,i_{pos},j,i_{pos+1},\ldots,i_n}}{\partial
A_{i_1,\ldots,i_n}} = 1
\] for all $j$.

During backpropagation, the incoming gradient  $\frac{\partial
L}{\partial C}$ (which has the broadcast dimension) must be summed along the broadcast dimension to match the shape of the input tensor according to the chain rule:\+    \[    \frac{\partial L}{\partial A_{i_1,\ldots,i_n}} = \sum_{j}
\frac{\partial L}{\partial C_{i_1,\ldots,i_{pos},j,i_{pos+1},\ldots,i_n}}
\]

The backward pass performs a sum reduction along the broadcast dimension, effectively gathering gradients from all the replicated copies back to the original tensor. This operation is the inverse of the forward broadcasting.

This \doxylink{classmattTorch_1_1GradFunction}{Grad\+Function} saves the input tensor from the forward pass to determine the shape for gradient reduction, and stores the position of the broadcast dimension.

Computes and propagates gradients for the broadcasting operation. 

Implements the backward pass for broadcasting by summing the incoming gradient along the broadcast dimension to match the shape of the input tensor. This gathers gradients from all replicated copies of the tensor back to the original shape, reflecting that each element of the input contributed to multiple elements of the output. The method calls \doxylink{classmattTorch_1_1function_1_1GradBroadcast_a82be11553bb34eb93c86ba4a36ca32ff}{backward()} on the parent tensor\textquotesingle{}s \doxylink{classmattTorch_1_1GradFunction}{Grad\+Function} to continue the backpropagation process.

When higher\+Derivative is false, gradient tracking is disabled on the saved tensor to prevent construction of a new computational graph during backpropagation.
