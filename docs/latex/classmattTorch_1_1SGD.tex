\doxysubsection{Detailed Description}
Stochastic Gradient Descent optimiser for updating network parameters. 

The \doxylink{classmattTorch_1_1SGD}{SGD} class implements the standard Stochastic Gradient Descent optimisation algorithm, in which each parameter is updated by subtracting its gradient scaled by the learning rate. The parameter update rule is:\+   \[    \theta_{t+1} = \theta_t - \alpha \nabla L(\theta_t)
\] where $\theta_t$ is the parameter value at step t, $\alpha$ is the learning rate, and $\nabla L(\theta_t)$ is the gradient of the loss with respect to the parameter.

The parameter update is performed using AVX2 SIMD intrinsics, processing 4 doubles at a time via fused negative multiply-\/add (FNMADD) instructions to compute (parameter -\/ learning\+Rate \texorpdfstring{$\ast$}{*} gradient) in a single operation.
