\doxysubsection{Detailed Description}
A dataset class for loading, storing and batching training data from CSV files. 

The dataset class handles the loading of labelled training data from CSV files, where the first column of each row is treated as the label and the remaining columns are treated as the feature values of the example. The loaded data is stored internally as two \doxylink{classmattTorch_1_1TensorView}{Tensor\+View} objects, one for the examples and one for the labels. The dataset supports shuffling of the example ordering via a Fisher-\/\+Yates shuffle on an internal index array, and provides batched access to the data via the get\+Batch method which returns a batch of examples and labels as new \doxylink{classmattTorch_1_1TensorView}{Tensor\+View} objects copied from the shuffled indices.

void matt\+Torch::\+dataset::\+load\+Data (\begin{DoxyParamCaption}\item[{const std::\+string \&}]{csv\+Path}{}\end{DoxyParamCaption})}



Loads labelled training data from a CSV file. 

Reads the specified CSV file, skipping the first row as a header. Each subsequent row is parsed as a comma-\/separated list of double values where the first column is treated as the label and the remaining columns are treated as the feature values of the example. The parsed data is stored internally as two \doxylink{classmattTorch_1_1TensorView}{Tensor\+View} objects of shape (num\+Examples x example\+Size) for the examples and (num\+Examples x 1) for the labels, and the internal index array is initialised to sequential ordering.
