\doxysubsection{Detailed Description}
Contiguous data storage for \doxylink{classmattTorch_1_1TensorView}{Tensor\+View} objects. 

The \doxylink{classmattTorch_1_1tensor_1_1TensorStorage}{Tensor\+Storage} class is responsible for holding the raw data associated with a \doxylink{classmattTorch_1_1TensorView}{Tensor\+View} object in a contiguous block of memory. \doxylink{classmattTorch_1_1tensor_1_1TensorStorage}{Tensor\+Storage} objects are not intended to be interacted with directly, but rather through the \doxylink{classmattTorch_1_1TensorView}{Tensor\+View} class which provides the primary interface for all tensor operations. The Tensor\+View-\/\+Tensor\+Storage structure is designed such that multiple \doxylink{classmattTorch_1_1TensorView}{Tensor\+View} objects can share a single \doxylink{classmattTorch_1_1tensor_1_1TensorStorage}{Tensor\+Storage} object, allowing for efficient memory usage when creating sub-\/tensor views or shallow copies of tensors.

\begin{DoxySeeAlso}{See also}
\doxylink{classmattTorch_1_1TensorView}{Tensor\+View} for the primary interface by which tensor objects are interacted with. 
\end{DoxySeeAlso}
