\doxysubsection{Detailed Description}
Gradient function for computing the mean of all elements in a tensor. 

The \doxylink{classmattTorch_1_1function_1_1GradMean}{Grad\+Mean} class represents the mean reduction operation in the computational graph, computing gradients for averaging all elements of a tensor into a single scalar value. For the operation  $c = \text{mean}(A) =
\frac{1}{N}\sum_{i} A_i$ where $A$ is a tensor and $N$ is the total number of elements, the gradient computation follows from:\+   \[    \frac{\partial c}{\partial A_i} = \frac{1}{N} \quad \text{for all } i
\]

During backpropagation, the incoming gradient  $\frac{\partial L}{\partial
c}$ (a scalar) must be distributed equally to all elements of the input tensor according to the chain rule:\+     \[    \frac{\partial L}{\partial A_i} = \frac{\partial L}{\partial c} \cdot
\frac{\partial c}{\partial A_i} = \frac{1}{N} \cdot \frac{\partial
L}{\partial c}
\]

The backward pass broadcasts the incoming gradient (divided by the number of elements) to match the shape of the input tensor, effectively distributing the gradient equally across all input elements.

This \doxylink{classmattTorch_1_1GradFunction}{Grad\+Function} saves the input tensor from the forward pass to determine the number of elements and the shape for broadcasting the gradient during the backward pass.

Computes and propagates gradients for the mean operation. 

Implements the backward pass for the mean reduction by dividing the incoming scalar gradient by the total number of elements in the input tensor and broadcasting it to match the input tensor\textquotesingle{}s shape. This distributes the gradient equally to all elements of the input tensor, reflecting that each element contributes equally to the mean. The method calls \doxylink{classmattTorch_1_1function_1_1GradMean_a498842b9eca2a4c71e2b840feff4f5aa}{backward()} on the parent tensor\textquotesingle{}s \doxylink{classmattTorch_1_1GradFunction}{Grad\+Function} to continue the backpropagation process.

When higher\+Derivative is false, gradient tracking is disabled on the saved tensor to prevent construction of a new computational graph during backpropagation.
