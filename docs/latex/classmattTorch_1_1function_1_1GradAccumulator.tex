\doxysubsection{Detailed Description}
Gradient function for leaf tensors that accumulates gradients during backpropagation. 

The \doxylink{classmattTorch_1_1function_1_1GradAccumulator}{Grad\+Accumulator} class is a specialised \doxylink{classmattTorch_1_1GradFunction}{Grad\+Function} used exclusively for leaf tensors in the computational graph. Unlike other \doxylink{classmattTorch_1_1GradFunction}{Grad\+Function} objects that compute gradients with respect to their inputs and pass them to parent nodes, the \doxylink{classmattTorch_1_1function_1_1GradAccumulator}{Grad\+Accumulator} terminates the backpropagation chain by accumulating the incoming gradient into the leaf tensor\textquotesingle{}s gradient storage. This allows leaf tensors such as learnable parameters in a neural network to collect the total gradient of the loss with respect to themselves.

When \doxylink{classmattTorch_1_1function_1_1GradAccumulator_aed14a7f0998d5eb3fc085d6ce65dd8b3}{backward()} is called for the first time, the incoming gradient is copied directly into the leaf tensor\textquotesingle{}s gradient. On subsequent calls during the same backward pass or across multiple backward passes, the incoming gradient is accumulated (summed) with the existing gradient. This accumulation behaviour is essential for computing gradients when a leaf tensor is used multiple times in the computational graph, as the total gradient is the sum of all partial gradients according to the multivariable chain rule.

When computing higher-\/order derivatives with higher\+Derivative set to true, the \doxylink{classmattTorch_1_1function_1_1GradAccumulator}{Grad\+Accumulator} enables the accumulated gradient itself to participate in a new computational graph by setting the gradient\textquotesingle{}s \doxylink{classmattTorch_1_1GradFunction}{Grad\+Function} to match the incoming gradient\textquotesingle{}s \doxylink{classmattTorch_1_1GradFunction}{Grad\+Function} and enabling gradient tracking on it. This allows derivatives of derivatives to be computed through subsequent backward passes.

Accumulates the incoming gradient into the leaf tensor\textquotesingle{}s gradient storage. 

Implements the gradient accumulation logic for leaf tensors. If this is the first gradient being accumulated (the leaf tensor does not yet have a gradient), the incoming gradient is copied directly into the gradient storage. If the leaf tensor already has a gradient, the incoming gradient is added elementwise to the existing gradient.

When higher\+Derivative is true, the accumulated gradient tensor is configured to participate in a new computational graph by setting its \doxylink{classmattTorch_1_1GradFunction}{Grad\+Function} to match the incoming gradient\textquotesingle{}s \doxylink{classmattTorch_1_1GradFunction}{Grad\+Function} and enabling gradient tracking on it. This enables computation of higher-\/order derivatives. When higher\+Derivative is false, the addition operation used for accumulation does not construct a computational graph.
