\doxysubsection{Detailed Description}
Gradient function for sum reduction along a specified dimension. 

The \doxylink{classmattTorch_1_1function_1_1GradReductionSum}{Grad\+Reduction\+Sum} class represents the sum reduction operation in the computational graph, computing gradients for summing a tensor along a specific dimension. For the operation $C = \sum_{i} A_i$ where the sum is taken along dimension $d$ of tensor $A$, the gradient computation follows from:\+   \[    \frac{\partial C_j}{\partial A_{j,i}} = 1 \quad \text{for all } i
\]

During backpropagation, the incoming gradient  $\frac{\partial
L}{\partial C}$ (which has one fewer dimension than the input) must be broadcast along the reduced dimension to match the shape of the input tensor according to the chain rule:\+    \[    \frac{\partial L}{\partial A_{j,i}} = \frac{\partial L}{\partial C_j}
\quad \text{for all } i
\]

The backward pass broadcasts the incoming gradient along the reduced dimension to restore the original tensor shape, effectively distributing the gradient to all elements that contributed to each sum. This operation is the inverse of the forward sum reduction.

This \doxylink{classmattTorch_1_1GradFunction}{Grad\+Function} saves the input tensor from the forward pass to determine the shape for broadcasting the gradient, and stores the dimension along which the reduction was performed.

Computes and propagates gradients for the sum reduction operation. 

Implements the backward pass for sum reduction by broadcasting the incoming gradient along the reduced dimension to match the shape of the input tensor. This distributes the gradient to all elements that contributed to each sum, reflecting that each element contributes equally (with a derivative of 1) to the sum. The method calls \doxylink{classmattTorch_1_1function_1_1GradReductionSum_ad53e1dd809a31c06fa0925d6a35ad715}{backward()} on the parent tensor\textquotesingle{}s \doxylink{classmattTorch_1_1GradFunction}{Grad\+Function} to continue the backpropagation process.

When higher\+Derivative is false, gradient tracking is disabled on the saved tensors to prevent construction of a new computational graph during backpropagation.
