\doxysubsection{Detailed Description}
A builder class for constructing \doxylink{classmattTorch_1_1Network}{Network} objects via a fluent interface. 

The \doxylink{classmattTorch_1_1NetworkBuilder}{Network\+Builder} class provides a convenient way to assemble a neural network layer by layer using method chaining. Layers and their associated learnable parameters are accumulated within the builder, and a final call to \doxylink{classmattTorch_1_1NetworkBuilder_a0bc68c7c0163c952c203696a4c6640bd}{build()} constructs the \doxylink{classmattTorch_1_1Network}{Network} object by transferring all layers and parameters to it. The builder takes ownership of the \doxylink{classmattTorch_1_1Layer}{Layer} objects created via its add methods and deallocates them in its destructor if \doxylink{classmattTorch_1_1NetworkBuilder_a0bc68c7c0163c952c203696a4c6640bd}{build()} has not been called.
