\doxysubsection{Detailed Description}
Mean Squared Error loss function for regression tasks. 

The \doxylink{classmattTorch_1_1criterion_1_1MSELoss}{MSELoss} class computes the Mean Squared Error between the predicted values and the target values. The loss is calculated as:\+   \[    L = \frac{1}{N} \sum_{i=1}^{N} (y_i - \hat{y}_i)^2
\] where $y_i$ is the target value, $\hat{y}_i$ is the predicted value, and $N$ is the total number of elements. The computation is performed by first computing the elementwise difference between the input and target tensors, squaring the difference elementwise, summing along dimension 1, and dividing by the total number of elements. Each of these operations participates in the computational graph, allowing gradients to be propagated back through the loss function during backpropagation.
