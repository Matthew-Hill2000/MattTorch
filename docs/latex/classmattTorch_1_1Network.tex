\doxysubsection{Detailed Description}
A sequential neural network composed of an ordered collection of layers. 

The \doxylink{classmattTorch_1_1Network}{Network} class represents a feedforward neural network in which an input tensor is passed sequentially through each layer in the order they were added. The \doxylink{classmattTorch_1_1Network}{Network} holds raw pointers to its \doxylink{classmattTorch_1_1Layer}{Layer} objects as well as shared pointers to all learnable parameter tensors across the network. \doxylink{classmattTorch_1_1Network}{Network} objects are intended to be constructed via the \doxylink{classmattTorch_1_1NetworkBuilder}{Network\+Builder} class, which provides a fluent interface for assembling layers and collecting their parameters.

The \doxylink{classmattTorch_1_1Network}{Network} class also provides functionality for saving and loading the learned parameter values to and from CSV files, as well as generating a text summary of the network architecture.
